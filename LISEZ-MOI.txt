VIGIE-Ecole-Team · VIGIE-École · LISEZ-MOI général
======================================================================
Data Challenge Burkina 2026, Édition Éducation · Défi 1 · mis à jour le 2026-11-17

VIGIE-École mesure l'abandon scolaire réel au primaire (corrigé des fermetures d'écoles), le prévoit dès la rentrée pour les 47 provinces,
explique ce qui pèse dans le risque et aide à décider où agir, sur le découpage de 2025 en 17 régions.

Par où commencer
---------------
1. Rapport final — comprendre le problème, les données, la méthode, les résultats et leurs limites.
2. Atlas national (8 pages) — voir où le risque se concentre et comparer les 17 régions.
3. Fiches des 17 régions — choisir une région et examiner ses alertes province par province.
4. Application — explorer les cartes et les fiches de façon interactive.

Les trois PDF sont dans livrables/05_interpretation.
Pour lancer l'application localement depuis la racine du projet :
  pip install -r livrables/app/requirements.txt
  streamlit run livrables/app/app.py

Les cinq dépôts
---------------
- 01_collecte          6 fichiers · Données brutes référencées, registre des sources, référentiel géographique
- 02_nettoyage        10 fichiers · Données propres et journal de nettoyage
- 03_transformation    9 fichiers · Base harmonisée, schéma, dictionnaire, plan du parcours
- 04_analyse          13 fichiers · Modèle, fiabilité, prévisions, facteurs, typologie
- 05_interpretation   24 fichiers · Fiches, atlas, documentation

Versions
--------
- v1 : tous les fichiers, sauf la série du primaire consolidée (02_nettoyage, v2 : années 2017-18 à 2024-25 reprises des tableaux détaillés).

Relancer tout le travail
------------------------
python livrables/app/relancer.py            (toutes les étapes, puis contrôle des sorties)
python livrables/app/relancer.py --depuis t09   (à partir d'une étape)

Autres dossiers
---------------
- donnees : sources brutes (annuaires, RGPH, ACLED, CONASUR, limites) ; - livrables/app : application et scripts (livrables/app/pipeline) ;
- pilotage : plan de travail et journal.
